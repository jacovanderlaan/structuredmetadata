Key concept SQL & generation

Cte Notebooks

Interactive, cell-by-cell SQL development with metadata round-tripping and a per-CTE advisor.

A development surface where SQL is built and run one CTE at a time while metadata flows in as you shape it — not only out at deploy. A built-in SQL Advisor does per-CTE static analysis: it flags separation-of-concerns violations, scores complexity, and warns on non-determinism.
